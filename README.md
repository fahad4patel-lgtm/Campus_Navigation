# Campus_Navigation
## Campus Navigation and Shortest-Path Finder  The **Campus Navigation and Shortest-Path Finder** is a navigation system designed to help students, faculty members, and visitors find the shortest route between different locations within a college campus. The campus consists of multiple buildings and facilities, including the Eco Campus, academic departments, canteens, stationery shop, library, Accounts Section, SFC counters, and parking areas.  The project represents the campus as a **weighted graph**, where locations are represented as vertices (nodes) and roads connecting them are represented as edges. Each edge is assigned an estimated distance to represent the length of the corresponding road. The system uses **Dijkstra’s shortest-path algorithm**, implemented in the C programming language, to calculate the shortest route between a selected starting point and destination.  The program identifies the minimum-distance path and displays the route along with its total estimated distance. This project demonstrates the practical application of fundamental Data Structures and Algorithms concepts, including graphs, adjacency matrices, arrays, and shortest-path algorithms.  An interactive webpage can also be used as an additional visual interface to display the campus map and illustrate routes between locations.  **The main objective** is to simplify campus navigation while demonstrating how graph-based algorithms can solve real-world pathfinding problems efficiently.
